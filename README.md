# PortfolioV2

Version 2 of my personal portfolio site, plus the assets that go with it.

Live: [maxlovinger.vercel.app](https://maxlovinger.vercel.app)

## Contents

| Path | What it is |
|---|---|
| `maxlovinger/` | The site: Next.js, TypeScript, Tailwind, shadcn/ui, Framer Motion, and a Three.js background. See [`maxlovinger/README.md`](maxlovinger/README.md). |
| `BTC Diamond Wood/` | The display font used for headings (OTF + WOFF/WOFF2), with its license |
| `Max Lovinger - Resume - 4_17_2026.docx.pdf` | The resume the site is based on |

## Run it

```bash
cd maxlovinger
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
